# ZP01 · Establish the registered padded reference

**Exit when** an explicit vacuum box reproduces an independent Fourier calculation on small fixtures and the candidate harness compares the same physical pixels in both arms. The parent already implements `fft_bins_v1`. Its tests and the registered coordinates are the starting contract.

1. **Freeze the specimen.** Define physical shape `(N, Ny, Nx)`, logical shape `(M, Ny, Nx)` with `M ≥ N`, equal voxel pitch `d`, and centered offset `o = (M-N)//2`. Use the same occupied voxels in A–D. Build B with literal vacuum (index 1, zero optical response, valid material fractions) outside those voxels. Share a vacuum material across arms where practical. Preserve contrast, orientations, normalization and energy order. Include `o=0` as a phase control. Start with window off. When testing the parent’s Hann mode, window the explicit box in B and use `hanning(M)[o:o+N]` times the same XY window in C.
2. **Specify the transform.** For an unnormalized forward XY transform `G[n,v,u]`, compute each requested native axial bin by

   $$F_M(m,v,u)=e^{-2\pi i m o/M}\sum_{n=0}^{N-1}G[n,v,u]e^{-2\pi i mn/M}.$$

   Retain the parent’s Igor-to-native index ordering. For a real basis reflect an omitted x half to `(-m mod M, -v mod Ny, -u mod Nx)` and conjugate before mixing complex optical coefficients. For a complex field use the full XY FFT. Include the neighbor amplitudes required by the existing DC replacement. Apply the offset phase to those coefficients before averaging. The `M=1` stencil has four lateral entries. When `M>1` it also has two axial entries. Preserve the parent’s multiplicities on short axes. Compare the raw DC, replacement and a low-q pixel next to it.
3. **Register the endpoints.** Use the parent’s `2π/(L d)` spacing on every axis with `L=M` only for z. The centered zero bin is `floor(L/2)`. Get both axial endpoints and weights from the parent’s forward Ewald geometry at the actual energy. Retain its exact-edge and final-row/final-column masks. Match B’s evaluation order by mixing coherent amplitudes, projecting each endpoint, forming intensities or rotation cross terms, and interpolating the endpoint results. Compare complex basis samples, mixed endpoints, raw validity masks, coordinate arrays, detector output and reduction separately.
4. **Use the maintained signed grating.** Extend [the grating fixture](../../../tests/validation/lib/ewald_registration.py) and [its Bragg test](../../../tests/validation/test_bragg_3d_lattice.py) with opt-in B/C cases. Use the existing `N=128` film, both signed transverse orders `±64`, `qx=0`, x polarization and physical depths `s=1,1.5` in units of the original axial spacing. Normalize by the existing exact on-bin intensity. Check both sampled columns against the following values for **both signs**.

| Axial depth s | A, M=128, bright / opposite | B and C, M=256 or 1024, bright / opposite |
|---:|---:|---:|
| 1 | 1 / 0 | 1 / 0 |
| 1.5 | 0.5 / 0 | 0.40530508 / 0.01623175 |

At `s=1.5` A interpolates intensities on two original bins. Both proposed pads put that same physical qz on an exact target bin. For a finite rectangular film, the bright and opposite intensities there are `[sinc(t)/sinc(t/N)]²` with `t=s−1` and `t=s+1`, respectively, using normalized sinc. The small opposite-order intensity is the finite-film sidelobe. Keep the native-depth test and its dark-column assertion. The [runnable NumPy oracle](../../../tests/validation/dev/cupy_rsoxs_virtual_zpad/check_fft.py) evaluates the two complex-coefficient methods, a literal dense FFT and these predictions.

**Coverage and harness.** Use odd/even rectangular grids, a noninteger pad ratio, `N=1`, `M=N`, both embeddings, Hann on/off and a seeded nonsymmetric anisotropic case with complex contrast and multiple E orientations. Include a same-process N→M→N run for stale geometry or cache keys. Report max absolute and relative L2 error with a scale for near-zero values. Set FP32 bounds from matched dense controls before judging candidates. Run [the parent grid checks](../../../tests/smoke/test_ewald_fft_grid.py), [DC validation](../../../tests/validation/test_ewald_fft_registration.py) and the signed grating on the applicable paths.

Extend [the speed harness](../../../tests/validation/dev/cupy_rsoxs_optimization/run_speed_tickets.py) so either comparison worker can request literal or virtual padding. Its existing `--transform-z` requires `--geometry` and only measures demand. Add a distinct execution option and record actual occupied depth, target depth, offset, convention, route and window for both workers. Compare omission and `M=N` to the parent through `Morphology.run`. Run a positive `M>N` sentinel whose grating output distinguishes an executed pad from an ignored option.
