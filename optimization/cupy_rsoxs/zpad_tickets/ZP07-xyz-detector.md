# ZP07 · Exact XYZ transform at the full logical detector

A $128^3$ source supplies the occupied geometry. A target $(M_z,M_y,M_x)$ sets all three Fourier spacings $2\pi/(M_i d)$ and the delivered detector shape $(M_y,M_x)$. The voxel pitch $d$ and the energy-dependent Ewald support set the accessible range. Greater span samples the same fixed particle more finely. A full panel is required even when many pixels are outside forward support. Preserve the established invalid-pixel representation for the chosen mask/layout.

## Implement and instrument

1. **Demand and storage.** Start with the logical detector's valid columns, their lower and upper axial neighbors, and the logical DC stencil. Reuse [the current Z implementation](../../../src/NRSS/backends/_cupy_virtual_z.py), the [energy basis](../../../src/NRSS/backends/_cupy_energy_basis.py), and the existing branch projection where they fit. Evaluate the union of required Fourier coefficients over an energy tile. Tile lateral columns, residue groups, basis rows or energies if the union is large. Stream the complete result into the requested host or device output. The intended working bound is occupied fields, bounded FFT/work tiles, endpoint storage for the current tile and the required output. A full logical morphology, a logical 3D complex cube and a logical 3D Boolean membership mask all defeat the purpose. Include FFT plan buffers, endpoint sorting, diagnostics and result assembly in the memory audit.
2. **Exact bins at integer ratios.** For $M=rn$ and native padded bin $k=r\ell+s$, transform $f(j)\exp(-2\pi i s j/M)$ with an $n$-point FFT and multiply by $\exp(-2\pi i k o/M)$ for its centered placement. Apply the identity along Y and X. General lateral phase ramps require complex FFTs, even for a real source. A $128\rightarrow1024$ lateral pad has 64 residue pairs, a $128\rightarrow8192$ pad has 4096. Batch or skip groups based on actual demand, measure launch and gather costs, and compute the two needed axial samples by a phased sum or a measured equivalent. Keep the public convention mapping Igor signed bins to native DFT bins and handle Hermitian partners before optical mixing. [The runnable CPU pilot](../../../tests/validation/dev/cupy_rsoxs_virtual_3dpad/residue_pilot.py) provides an independent, unwindowed scalar example for integer cubes.
3. **Exact arbitrary shapes.** Handle arbitrary rectangular target lengths including unchanged axes and non-integer ratios. A useful initial path computes occupied-slice XY transforms on one padded plane or a bounded batch, gathers required frequencies, then accumulates the Z sums into endpoint tiles. A tiled chirp-Z or blocked exact sum is another implementation. Include slice offset and window phase. Bound the live working set and profile repeat passes. A path can be slower on awkward factors and still be correct. Never round a target up to a friendly FFT length for its actual physical grid. Test an explicit allocation failure produces a clear error with the requested shape or successfully retries with a smaller internal tile.
4. **Detector and results.** Follow `shape_override` through `_detector_geometry`, `_detector_projection_geometry`, the compact projection and [rotation kernels](../../../src/NRSS/backends/_cupy_compact_rotation.py). In [cupy_rsoxs.py](../../../src/NRSS/backends/cupy_rsoxs.py), inspect `_detector_q_axes`, `_rotation_transforms`, detector/result materialization and the integrated q-axis/mask caches. Some paths on the parent use occupied YX. Use logical YX in rotation centers/warps, stride products, intermediate/output buffers, q reductions and axis labels. Consume the two **projected endpoint intensities** and the registered axial interpolation weight in the same order as the parent. Keep the original pixel pitch and `fft_bins_v1` axis, DC center and border behavior. A Z-only-equivalent XYZ request must reproduce Z padding with the same fill and window.
5. **Large IDs and reuse.** Build flattened IDs and dimension products in 64-bit arithmetic before multiplication, including kernels, sort keys, gather/scatter, flattened DC indices and any global offsets. At $8192^3$ the logical address space contains $2^{39}$ bins. Test a synthetic high signed bin with an address above $2^{31}$ without allocating the cube. Cache keys must distinguish occupied and logical shapes, placement, pitch, window, energy set, projection/rotation geometry and changes to fill or material optics wherever relevant. Reuse pure geometry across energies and fill selections where valid. Record buffer and endpoint counts, tile sizes, FFT counts, mask-builds and reruns in diagnostic mode.
6. **Public provenance.** Preserve existing Z metadata for old calls. For extended calls expose an auditable pad mode, original/transform ZYX shapes, centered offsets, effective XY and Z windows, and fill choice on detector and integrated results. Use serialization-safe attributes, e.g. a numeric `pad_material_id` for a selected ID, a `"vacuum"` fill tag for `None` and an `"S=0"` convention for numbered fill. Preserve logical `z_dim` and radial semantics. Use executed route names beginning with `virtual_3d` in the private execution diagnostics. Ordinary identities take the normal native route. Add a round-trip serialization check.

## GPU evidence required

| Fixture | Fault it should expose |
|---|---|
| `(5,7,8) → (14,16,19)` and `(5,14,16)`, both windows | Mixed parity, centering phase, axis swaps and XY-only expansion. Compare all complex coefficients on a small box |
| `(5,7,8) → (17,7,8)` using each public selector separately | Independent Z and XYZ implementations must agree for the same logical object |
| Shifted off-axis complex inclusion with unequal X/Y frequency, absorbing oriented material, laterally translated copies | Sign, conjugation, polarization cross terms, DC and rectangular-center registration. Compare each placement to its own literal target |
| Multi-energy, a single E angle and a 12-angle scan | Energy coefficient reuse, angle combination, mask/warp origin and same-process invalidation |
| Host and device output, detector and supported integrated layouts, intersection/union | Logical q coordinates, finite masks, channel order, absolute levels and returned shape |
| Large sparse endpoint IDs and a forced allocation failure | Overflow and a silent reversion to native resolution |

Use ZP06 numerical limits on like-for-like computational comparisons. Capture complete small panels and the first axial and lateral neighbors. Check independent masks, exact axes and data ordering. For every route confirm that private dispatch reached it. In the development ledger distinguish storage paid once, storage per current tile and storage scaling with the final panel.
