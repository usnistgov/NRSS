# ZP05 · Public options and literal references

Build one geometry and fill contract for the CuPy compact tensor-coefficient route. Read the option allowlist, normalization and backend defaults in [contracts.py](../../../src/NRSS/backends/contracts.py), morphology initialization and material registration in [morphology.py](../../../src/NRSS/morphology.py), and `_virtual_z_shape` in [cupy_rsoxs.py](../../../src/NRSS/backends/cupy_rsoxs.py). Follow the current public `Morphology(..., backend="cupy-rsoxs", backend_options=...)` entry point and read-only `backend_options` view. Stage callable options together with their executable route.

| Options in `backend_options` | User-visible behavior |
|---|---|
| Omit both targets | Native shape and the existing window, detector and intensity contracts |
| `virtual_z_pad_to=1024` | Extend Z to 1024, retaining the occupied YX shape |
| `virtual_3d_pad_to=1024` | Center the crop inside exactly `(1024, 1024, 1024)` voxels |
| `virtual_3d_pad_to=(Mz, My, Mx)` | Exact target in **ZYX** order, including nonsquare lateral grids. Accept the equivalent three-element list |
| `virtual_pad_material=None` or omitted | Vacuum exterior in either padding mode |
| `virtual_pad_material=j` | Exterior occupied entirely by the isotropic response of morphology material number `j`, at each simulated energy |

For example, extend a `(128,128,128)` crop in its registered material 2 with `{"virtual_3d_pad_to": 1024, "virtual_pad_material": 2}`. The existing film can use `{"virtual_z_pad_to": 1024, "virtual_z_method": "sum", "virtual_pad_material": 2}`. A numbered material need only be registered and have valid optics, including when its occupied input fraction is zero. Look up the actual morphology material key. Default `None` works on old saved configurations and does not require a synthetic material.

**Validate at the boundary.** Accept positive integral counts and registered integer material IDs, including integer scalar types. Reject booleans, floats, strings, malformed tuples, a target below the occupied length on any axis, and unknown material numbers. Reject two active pad targets even if one requests an identity, a numbered fill with neither target, and an explicit `virtual_z_method` accompanying XYZ. Distinguish an explicitly supplied selector from a normalized Z default. Omitted fill or standalone `None` remains valid. Validate shape and ID when materials are bound, and on a run if subsequently changed. Exercise construction and stale-cache invalidation, following the private same-process mutation check the branch already uses for Z padding. Validate identity options first, then use existing native calculation and native windowing when all sizes match. Geometry must leave `Morphology.NumZYX` equal to the supplied crop. Use the parent eligibility rules where an extension needs the compact basis. Surface unsupported combinations through a descriptive error.

**Geometry and finite medium.** For each axis use offset $o_i=\lfloor(M_i-n_i)/2\rfloor$. The high-index side gets any extra voxel. The inside is the whole supplied crop, including any internal void or matrix. Only its exterior gets the selected fill. Preserve every interior fraction, orientation and order parameter. A genuine extension uses the caller's `WindowingType`. For `0` the amplitude weight is one. For `1` it is `hanning(My)[y] * hanning(Mx)[x]` on logical coordinates everywhere, with unit weight along Z. Crop the lateral window at the centered offset when processing stored data. This defines the new XYZ window convention and reduces to ZP04 for fixed lateral dimensions. It represents a finite, homogeneously filled box. Refractive changes to Ewald geometry and infinite-medium scattering are separate physical models.

**Reference fixtures.** Extend [the literal padding helpers](../../../tests/validation/lib/virtual_z_padding.py). Build a physically occupied target of the same dimensions, pitch and optical table. Copy the original fields into the center. Outside it use fraction 1 for the selected material and 0 for every other material. For a non-enum material set exterior `S=0` and finite dummy Euler angles. Preserve enum sentinels for isotropic source materials. Use a registered zero-optics material for a physical vacuum reference where fraction closure is required. Apply the logical XY window once at the scattering-field stage using the explicit-reference hook, with the native XYZ taper disabled. Run both with the ordinary API. Include signed complex Fourier comparisons independent of the candidate and detector comparisons in absolute units.

Run `python tests/validation/dev/cupy_rsoxs_virtual_3dpad/check_material_fill.py`. Its three small geometries cover both windows, four fills, two energy tables and five tensor components. It checks 96 complex comparisons against literal boxes, before and after DC repair. Port representative fixtures to maintained CPU/GPU tests. Include an odd rectangular target, a homogeneous filled specimen, a particle with a matrix-filled interior, a hole inside the input crop and a non-axis-aligned anisotropic region.
