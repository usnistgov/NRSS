# QM01 · Freeze the parent and the requested detector region

**Deliverable.** Record the final local speed SHA, environment and selected routes. Run the README's A/A controls. Add one optional `q_max` entry to the CuPy backend contract and public documentation, in nm⁻¹. Accept finite nonnegative real scalars including zero. Reject booleans, strings, negative values, NaN and infinity. No cutoff is `None` or omission. Preserve normal automatic selection of compact tensor with reuse.

**Cartesian detector, the primary contract.** Work on the existing logical qx/qy axes and include the boundary. On the 2D reciprocal-plane route use transverse radius. For 3D use the continuous forward-Ewald magnitude for each energy at the requested output pixel. With `k = 2π E / 1239.84197` and `r = hypot(qx,qy)`, the published convention gives `q = sqrt(r² + (sqrt(k²-r²)-k)²)` for `r ≤ k`. Endpoint-interpolated intensity still comes from the existing machinery. Test the cutoff comparison in float64 at exact bins and neighboring representable cutoffs. Base membership on geometry, independent of sample intensity, RotMask and material.

Return the smallest common axis-aligned rectangle containing the requested pixels across the energies. Copy the original qx/qy index slices exactly. Each energy keeps every incumbent bit in its own requested disk, including existing zeros, signed zeros and NaNs. The rectangle's other cells are NaN. A zero cutoff includes the original DC pixel. A finite cutoff above the forward support uses the same finite-q selection of the parent. Omission retains the entire existing rectangular output. Record the original logical shape, crop offsets and requested limit when opted in. Keep existing transform metadata and origin. This is one proposed public shape choice. No second user-facing crop mode is needed.

**Reduced layouts.** For `integrated`, `i_only`, `i_para_i_perp` and `i_a`, construct the existing full one-dimensional coordinates, then select their original indices at finite physical q ≤ the cutoff. Keep every coordinate, per-energy attribute, bit and mask equal to the corresponding full result there. For a shared grid select by its `q`, and slice the auxiliary `q_abs` by the same public indices. The gather of native source bins for computation is separate. For the `per_slice_q_abs` fallback, take the union of retained positional indices and mask unsupported energy/bin pairs. Preserve the parent's union/intersection semantics, input energy order and native 2D q convention. [Registered grid documentation](../../../docs/source/user_guide/cupy_rsoxs_result_q_grids.rst)

**First tests.** Compare real default-dispatch returns with [the independent reference](../../../tests/validation/dev/cupy_rsoxs_qmax/qmax_reference.py). Cover one nonzero cutoff, a bin reached exactly, float64 nextafter on both sides, zero, above support, and omission. Include permuted soft/hard energies and mixed odd/even rectangles. Use the original dtype and bit pattern for each retained scalar, plus exact numeric coordinate bytes. An unchanged full detector masked only at export may serve as an intermediate correctness control. Advance to QM02 for actual allocation and execution savings.

For automatic allocation fallback, retain the requested product and record the route actually executed. Compare it with the matching incumbent fallback on the same geometry. Cover a supported same-object options change and result release.
