# QM02 · Propagate pixel demand into the shared compact planner

**Deliverable.** A single demand description for native compact, virtual Z and virtual XYZ. It identifies the public output indices and the internal source indices needed to reproduce them. Plan it before building the energy basis. Construct the small logical 1D axes at full precision and represent the active Cartesian domain with bounded masks, rectangles, runs or packed columns. Compare a cheap conservative region with exact packed demand. Charge setup time and storage to the candidate.

1. For raw detector output begin with each energy's requested disk on the global grid. Map each required output pixel through the incumbent inverse rotation for every E direction and include the original bilinear reads and border behavior. For reduced output, trace backward from retained radial bins through the energy-specific common-q brackets and the 360-ray polar interpolation before reversing E rotations. Preserve the exact pixel-center convention. On odd sizes the FFT zero index and the affine transform's half-dimension center can differ. On rectangles a rotation in pixel space does not preserve a circle in physical q.
2. Intersect source requests with the parent's forward support at that energy. Include both axial endpoints, exact interpolation weights, the repaired DC dependency stencil, and native Hermitian reflections in all three axes. Preserve parent behavior for existing invalid samples, RotMask, zero-weight neighbor evaluation and angle accumulation order. Keep optical contractions, projection at each endpoint, interpolation of endpoint powers and reuse across energy intact. For Ewald radius cutoffs above the forward physical support, stop at the support boundary.
3. Keep global index/stride arithmetic 64-bit. Keep coordinates in the original frame through all indexing, affine offsets and FP32 rounding. Prefer dispatching the incumbent per-pixel math with a global index offset as the first experiment. Replacing `m * (index + offset)` with reassociated operations can move a bilinear sample by an ULP. Preserve original kernel arithmetic and compiler math flags.
4. Keep public buffer sizes, private halos and actual launches measurable separately. Instrument returned cells/bytes, valid requested cells, source projection pixels, unique Fourier endpoints, FFT calls/shapes, live basis/workspace bytes and fallback reasons. Reuse plans only under the original logical dimensions/pitch, ordered schedule, angles, grid, output layout, cutoff and other inputs that determine the plan. Recheck the same object after changing cutoff and after release/fallback.

**Accept.** The exact output region and every source lookup agree with an independently enumerated small full-grid reference. The odd rectangular [dependency probe](../../../tests/validation/dev/cupy_rsoxs_qmax/probe_dependencies.py) covers a concrete fixed-halo failure. Check raw panels first at one angle and the 12-angle sweep, then reduced layouts across the cutoff. Exercise asymmetric off-axis data, near-boundary NaNs, signed zero, DC and a deliberately dark sector. Require zero mismatches within the window. A diagnostic must demonstrate fewer source pixels processed and a smaller returned buffer for an interior cutoff.
